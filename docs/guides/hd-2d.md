# HD-2D

- **Covers:** `world-drawing/diorama`
- **Status:** planned
- **Tickets:** 3107, 3109

A 2D game drawn as a diorama: flat sprites standing in a 3D world, with
depth, light and a tilted camera. The rules stay 2D, a grid or a free
world; only the skin changes. Ticket 3107 builds the skin,
`shuyi-diorama`, and ticket 3109 the top-down 3D and HD-2D example and
templates, which write this guide in full.

## Until then

- Build the game on its 2D direction, the [top-down grid](top-down-grid.md)
  for one, and keep its look in its skin. A diorama will be another skin
  over the same scene.
- Don't put height or a camera in the rules for the look's sake: a
  game whose rules need height is [top-down 3D](top-down-3d.md).
