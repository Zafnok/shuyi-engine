The book teaches Shuyi Engine one idea at a time: a quick start, then a chapter
for each idea the engine rests on. You don't need to know Rust or to have made a
game before. Each chapter says what its idea is for before it names it, explains
the Rust its code uses, and shows what it looks like when something goes wrong.

The [tutorial](@/learn/tutorial/_index.md) and the book are two ways in. The
tutorial builds one whole game in order, a step at a time. The book takes one idea
and looks at it from every side, so it's also where you come back to when you want
to know how something works. If you have never programmed, start with the
tutorial's [Before you start](@/learn/tutorial/00-start.md). The tutorial's
[glossary](@/learn/tutorial/glossary.md) lists the words of both.

Read the book in order the first time. Every chapter uses the same small game,
**Moon Garden**: a row of plots, a handful of seeds, and some luck. Every piece of
code in it, and every picture, is built and tested with the engine, so it works
with the engine of the same day.
