An open-source 2D game engine in Rust, built so that you **and your coding
agent** can make, run, see, test and replay a game without a window and
without guessing.

Early, and not yet released: it runs one game today,
[Visions of Shuyi](https://github.com/Zafnok/visions-of-shuyi), and one
example, and its API still moves.
