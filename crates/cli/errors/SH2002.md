# SH2002: A text file isn't valid UTF-8

Class: content, exit code 1.

A file read by a text format holds bytes that aren't UTF-8 text: it was
saved in another encoding (Latin-1, UTF-16), or a binary file was given
a text file's name.

**How to fix it.** Save the file as UTF-8 text in its editor, or give a
binary file the extension of its own format.

For example:

```text
files/names.ron: error[SH2002]: file is not valid UTF-8
```
