# SH3007: The record was made by another build or with other content

Class: operation, exit code 1.

`replay` read a record whose stamp (what made it: the engine's version,
the game's word for its build, and the fingerprint of its content)
isn't this build's. Its runs could differ from the ones it was made
with for that reason alone, which would look like a desync and isn't
one, so it isn't run. The message names the record and each part that
differs, with both values.

**How to fix it.** Make the record again with this build (the game's
`bots` writes records with this build's stamp). To run it anyway, pass
`--any-stamp` (`any_stamp: true` in the input): the answer's limits
then say a difference may come from the stamp.

For example:

```text
replay: error[SH3007]: records/a.ron was made with content 1a2b3c4d5e6f7a8b; this build: content 3c4d5e6f7a8b9c0d: make it again with this build, or replay it with --any-stamp
```
