# SH2005: No format reads the file

Class: content, exit code 1.

No format registered for the asset's kind knows the file's bytes or
claims its extension. The message lists the kind's formats; `import`
lists the kinds it tried.

**How to fix it.** Give the file an extension one of the listed formats
claims, convert it to one of them, or register a format that reads it
(`Formats::register`).

For example:

```text
notes/a.txt: error[SH2005]: no image format knows its bytes or claims its extension "txt"; the image formats are png, txtimg
```
