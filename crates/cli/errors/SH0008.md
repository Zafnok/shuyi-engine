# SH0008: The worktree to seed is the one the command runs in

Class: usage, exit code 2.

`shuyi seed-target` runs in the warm checkout, the one that has built,
and `--into` names the new worktree it seeds. Here `--into` named the
worktree the command runs in: a worktree can't be seeded from itself.
This is what happens when the command is run from inside the new
worktree with `--into .`.

**How to fix it.** Run it in the warm checkout instead, the first line
of `git worktree list --porcelain`, with `--into` the new worktree's
folder. From the new worktree, in Bash:

```bash
main=$(git worktree list --porcelain | sed -n '1s/^worktree //p')
(cd "$main" && cargo shuyi seed-target --into "$OLDPWD")
```

For example:

```text
seed-target: error[SH0008]: D:/games/moon-garden: that is the donor itself; run this in the warm worktree, with --into the new one
```
