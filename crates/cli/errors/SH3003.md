# SH3003: No such target, or the target profiles don't load

Class: operation, exit code 1.

`check --target`, `bake --target` or `frame-png --target` named a target
the engine and the game have no profile for, or the game's target
profiles don't load.

**How to fix it.** Name one of the targets the message lists, add its
profile, or fix the profile file the message names.

For example:

```text
check: error[SH3003]: no target profile "wii"; the profiles are desktop, playdate, web
```
