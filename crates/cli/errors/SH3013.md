# SH3013: The repository exists, and you can't administer it

Class: operation, exit code 1.

`shuyi repos` sets up two repositories: the game's (`--owner` and
`--name`, or the folder's `origin`) and its private files' (`shuyi.ron`'s
`private_assets.url`). One of them exists, and the account `gh` is
signed in as isn't an admin of it, so `repos` can't add its deploy keys,
set its secrets or put its ruleset on it. The message names the
repository. Nothing was made.

**How to fix it.** Sign `gh` in as the repository's owner, or as an
admin of it (`gh auth login`; `gh auth switch` picks among accounts
already signed in). If it is someone else's repository of the same name,
pick another: `--owner` or `--name` for the game's, and for the private
one the `url` of `shuyi.ron`'s `private_assets`. Then run `shuyi repos`
again.

For example:

```text
repos: error[SH3013]: https://github.com/studio/moon-garden-assets exists, and you can't administer it: its keys, secrets and rulesets need an admin
```
