# SH2008: A name in the file isn't one it may use

Class: content, exit code 1.

The file names something that isn't there: in `keymap.ron`, an action
the game doesn't have, or a key chord or button that doesn't parse; in a
map, a legend's terrain the game doesn't know, or a tile character the
legend doesn't give.

**How to fix it.** Use one of the names the message lists, or fix the
spelling. A key or button is named as `controls.md` writes it; a tile
character needs a line in the map's legend.

For example:

```text
base/data/keymap.ron:7: error[SH2008]: layout "LeftHanded": unknown action "Jumpp"; known actions: Up, Down, Left, Right, Jump
```
