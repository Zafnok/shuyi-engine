# SH3020: The debug file doesn't read as a program

Class: operation, exit code 1.

`shuyi crash --symbols <file>` names a crash report's frames from the
debug file of the build that crashed: the program as it was built
before it was stripped, with its line tables, which `shuyi export
--release` keeps beside the package as `<package>.debug`
(`docs/crash-reports.md`). The file given was read, but isn't a program
in a form `crash` reads (PE or ELF): a zip or `tar.gz` package, a
macOS program, a PDB file from an MSVC build, or a file cut short when
it was copied.

**How to fix it.** Give the `.debug` file kept for the report's build,
whole: for a game's release, `gh release download <tag>-debug` fetches
it. The message ends with the reason the file didn't read.

For example:

```text
crash: error[SH3020]: notes.txt: Could not read file magic
```
