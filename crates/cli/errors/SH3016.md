# SH3016: A cargo build is running in one of the worktrees

Class: operation, exit code 1.

`shuyi seed-target` holds the locks cargo takes in both worktrees'
`target/debug/` while it seeds, so no build writes there under it. One
of them was held: a cargo build (or a test, or the MCP server's build as
a session starts) is running in the warm checkout or in the new
worktree. The message names the lock file. Nothing was written.

**How to fix it.** Wait for that build to finish, then run
`seed-target` again. What the new worktree built meanwhile is kept: the
seed adds only what it lacks.

For example:

```text
seed-target: error[SH3016]: D:/games/moon-garden-wt/target/debug/.cargo-lock is locked: a cargo build is running there; wait for it to finish
```
