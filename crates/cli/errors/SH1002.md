# SH1002: shuyi.ron doesn't read, or lacks what the command needs

Class: setup, exit code 3.

The project file was found but can't be used for this command: it
doesn't read (a RON error, an unknown field), it lacks the part a
command needs (`check_keys`, `web`, ...), or it names no game tool
program (`game`) and the command runs the game.

**How to fix it.** Fix `shuyi.ron` as the message says: the RON error's
line and column, or the part to add. The templates' `shuyi.ron` shows
each part written. Then run the same command again.

For example:

```text
check: error[SH1002]: shuyi.ron names no game tool program (`game`), and check runs the game
```
