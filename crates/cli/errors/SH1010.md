# SH1010: The game is in no git repository of its own

Class: setup, exit code 3.

`shuyi trim-targets` and `shuyi seed-target` act on the worktrees of the
game's git repository: the folders `git worktree list` lists. The game's
folder is in no git repository, or it is inside another repository that
ignores it (a game made in a `target/` folder), so it has no worktrees of
its own to act on. Nothing was read or deleted.

**How to fix it.** Put the game in git: `shuyi repos` makes its
repository on GitHub, or `git init` makes one on this machine. Then run
the same command again.

For example:

```text
trim-targets: error[SH1010]: D:/games/moon-garden is in no git repository
```
