# SH0006: GitHub refuses the repository's name, or it is taken

Class: usage, exit code 2.

`shuyi repos` names the game's repository with `--name`, or from
`shuyi.ron`'s `app.name` (`Visions of Shuyi` makes `visions-of-shuyi`).
GitHub takes a name of letters, digits, `.`, `-` and `_`, at most 100
characters, not `.` or `..` and not ending in `.git`. The name broke one
of these, or the app's name makes no name at all (it needs a letter
first). Or the name is taken: a repository of that owner and name
already has commits, and the game's folder has no `origin` naming it, so
`repos` won't push the game into it.

**How to fix it.** Pass another name with `--name`. If the repository
that is there is this game's, add it as the folder's `origin` instead
(`git remote add origin https://github.com/<owner>/<name>.git`): `repos`
then uses it as it is. Then run `shuyi repos` again.

For example:

```text
repos: error[SH0006]: https://github.com/you/moon-garden is taken: it already has a branch main, and this folder has no origin
```
