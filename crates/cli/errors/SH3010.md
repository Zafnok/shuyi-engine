# SH3010: The target has no exporter, or no run step, yet

Class: operation, exit code 1.

The game passes the target's check, but `export` can't build for it:
there is no exporter for that target yet. The message lists the
targets that have one. Or the export was made, and `--run` asked to run
it, but the target has no run step yet: the package is written, and the
report with it.

**How to fix it.** Export for a target the message lists. To run a
package that has no run step, open it by hand: on another system, or in
the browser for the web build.

For example:

```text
export: error[SH3010]: steam-deck passes check --target steam-deck, but there is no exporter for it yet (the exporters: windows, linux, macos, web)
```
