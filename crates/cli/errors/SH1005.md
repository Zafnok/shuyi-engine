# SH1005: No build is listening at the address

Class: setup, exit code 3.

`attach` (or MCP's `start` with `link`) reaches a build that is already
running, over the live link, and nothing listens at the address it was given: the build isn't
running, it was built without its backend's `link` feature, it was
started without `SHUYI_LINK`, it is a build without debug tools (a
release build), or the port is another.

**How to fix it.** Start the game's debug build with the link:

```text
SHUYI_LINK=0 cargo run --features link
```

(`0` takes a free port; a number takes that one.) Its log says where it
listens and its token; attach to that address with that token.

For example:

```text
attach: error[SH1005]: no build is listening at 127.0.0.1:7357: No connection could be made because the target machine actively refused it. (os error 10061)
```
