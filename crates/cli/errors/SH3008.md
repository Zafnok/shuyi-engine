# SH3008: The target's check found errors, so nothing was exported

Class: operation, exit code 1.

`export` starts with the target's check, `check --target` with the
target's profile (`desktop` for `windows`, `linux` and `macos`). That
check found at least one error, a frame that doesn't fit the display or
a required action with no button, say, so the game wasn't built for it.
The message lists each error with the setting it is about.

**How to fix it.** Fix each error as the message says: `check --target
<profile>` shows the same list, with its warnings. Then export again.
Warnings don't stop an export: `export-report.json` lists them.

For example:

```text
export: error[SH3008]: check --target playdate found errors; nothing was built:
  targets."playdate".frame: the frame (800 × 512) at scale 1 doesn't fit the display (400 × 240)
```
