# SH3019: The crash report holds no record of the game's play

Class: operation, exit code 1.

`shuyi replay --crash` replays the record of play a crash report holds
(its `record`), and this one holds none. A web report never does, nor a
report of a panic before a stage was open. A game whose `Start` gives no
`crash_record` writes none, and a release build writes one only when the
game asks for it (`CrashReports::with_record_in_release`).

**How to fix it.** `shuyi crash <report>` still reads the report: its
message, place, frames and log. To replay the next crash, give `Start` a
`crash_record` (`BasicGame::crash_record` on the short path), and in a
release build ask for it with `with_record_in_release`.

For example:

```text
replay: error[SH3019]: crash-1700000000123.ron holds no record of the game's play: a web report, a panic before a stage was open, or a game whose tools give no crash_record
```
