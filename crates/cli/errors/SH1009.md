# SH1009: gh's sign-in lacks a scope shuyi repos needs

Class: setup, exit code 3.

`gh`'s sign-in carries scopes: what it may do on your account. `shuyi
repos` needs `repo`, to make the repositories, their deploy keys,
secrets and ruleset, and `workflow`, to push the game's workflows in
`.github/workflows/`. `gh auth status` listed scopes without one of them.
The message names the one missing. Nothing was made.

**How to fix it.** Run `gh auth refresh -h github.com -s repo,workflow`
and approve it in the browser, then run `shuyi repos` again.

For example:

```text
repos: error[SH1009]: gh's sign-in lacks the scope workflow
```
