# SH1011: The warm checkout has no build to seed from

Class: setup, exit code 3.

`shuyi seed-target` hard-links the warm checkout's compiled third-party
crates, in its `target/debug/`, into the new worktree. The worktree it
ran in has no `target/debug/`: it has never built, so there is nothing
to seed from. Nothing was written.

**How to fix it.** Run it in a worktree that has built, usually the
main checkout (the first line of `git worktree list --porcelain`). Or
build there first, `cargo test --workspace --no-run`, then run
`seed-target` again.

For example:

```text
seed-target: error[SH1011]: D:/games/moon-garden/target/debug: the donor has no build to seed from
```
