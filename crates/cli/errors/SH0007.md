# SH0007: The folder is no worktree of this repository

Class: usage, exit code 2.

`shuyi seed-target --into <worktree>` starts a new worktree's `target/`
from the one it runs in. It runs in the warm checkout, and `--into`
names the new worktree: a folder that `git worktree list` lists for the
same repository. The folder given doesn't exist, or it is a folder of
its own, not one of the repository's worktrees. Nothing was written: a
seed never makes a `target/` in a folder that isn't a worktree.

**How to fix it.** Make the worktree first (`git worktree add <folder>`;
Codex and Claude Code make theirs the same way), then pass its folder to
`--into`, from the warm checkout. `git worktree list` lists every
worktree's folder.

For example:

```text
seed-target: error[SH0007]: D:/games/moon-garden/crates is no worktree of this repository (git worktree list lists D:/games/moon-garden)
```
