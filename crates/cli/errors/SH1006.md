# SH1006: The build speaks another link version than this shuyi

Class: setup, exit code 3.

`attach` (or MCP's `start` with `link`) and the build it reached speak the live link in two versions:
the build was made with another engine than this `shuyi`. It answered
the hello with its version and closed the link.

**How to fix it.** Attach with the `shuyi` of the engine the build was
made with (the game's own `cargo shuyi`, at the engine its `Cargo.toml`
pins), or build the game again on this engine and start it again; then
attach again.

For example:

```text
attach: error[SH1006]: the build at 127.0.0.1:7357 speaks link version 2, and this shuyi 1
```
