# SH1001: No shuyi.ron here or in a folder above

Class: setup, exit code 3.

A command that runs on a project found no `shuyi.ron` in the working
folder or any folder above it. Every command but `new`, `doctor`,
`schema` and `explain` needs one.

**How to fix it.** Run the command in a game's folder, or a folder below
it. To start a game, `shuyi new <dir> --template grid` or `shuyi new <dir> --template blank`
makes one with its `shuyi.ron`. Then run the same command again.

For example:

```text
check: error[SH1001]: no shuyi.ron in /home/me/notes or a folder above it
```
