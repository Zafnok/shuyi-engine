# SH1003: A piece of the toolchain is missing

Class: setup, exit code 3.

A program the command needs didn't start (cargo, to run the game's tool
program), or `doctor` found a check that failed: Rust, Cargo, rustup,
MSYS2's linker on the Windows GNU toolchain, or the web target.

**How to fix it.** Run `shuyi doctor`: each failed check says how to fix
it. Fix each, run `doctor` again until it passes, then run the same
command again.

For example:

```text
doctor: error[SH1003]: A piece of the toolchain is missing
```
