# SH1003: A piece of the toolchain is missing

Class: setup, exit code 3.

A program the command needs didn't start (cargo, to run the game's tool
program), or `doctor` found a check that failed: Rust, Cargo, rustup,
MSYS2's linker on the Windows GNU toolchain, on Linux the C linker,
`pkg-config` or a system library, or the web target. `export` answers it
too for a tool its package needs: `objcopy` for a release `windows` or
`linux` package, Binaryen's `wasm-opt` for a release `web` one.

**How to fix it.** For an export's tool, install it as the message says
(or, for `wasm-opt`, set `export.wasm_opt: optional` in `shuyi.ron` to
ship the web build unoptimized). Otherwise run `shuyi doctor`: each failed
check says how to fix it. Fix each, run `doctor` again until it passes, then run the same
command again. On Linux, `bash scripts/setup-linux.sh` (in the engine and
in a game made with `shuyi new`) installs everything doctor checks.

For example:

```text
doctor: error[SH1003]: A piece of the toolchain is missing
```
