# SH2003: A file isn't there

Class: content, exit code 1.

A file the game's content asks for isn't in the asset bundle: a path
misspelt, a file not yet added, or one left out of the layers the target
ships. When the asset was named without an extension, the message lists
every file tried.

**How to fix it.** Add the file at that path, or fix the name that asks
for it. Paths are relative to the bundle's layer and written with `/`.

For example:

```text
base/images/card: error[SH2003]: file not found in asset bundle, nor images/card.png
```
