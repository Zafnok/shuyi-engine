# SH1007: GitHub's CLI, gh, isn't installed

Class: setup, exit code 3.

`shuyi repos` makes the game's repositories, deploy keys and secrets on
GitHub through `gh`, GitHub's own command-line tool, signed in to your
account. It didn't find `gh` on your `PATH`. Nothing was made.
`shuyi doctor` lists `gh` as optional: only `repos` needs it.

**How to fix it.** Install `gh` from <https://cli.github.com> (on
Windows, `winget install -e --id GitHub.cli`; then open a new terminal,
so that it is on the `PATH`). Sign in with `gh auth login`, then run
`shuyi repos` again.

For example:

```text
repos: error[SH1007]: gh, GitHub's CLI, isn't installed
```
