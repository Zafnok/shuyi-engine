# SH2009: Something given once is given twice

Class: content, exit code 1.

The file gives twice what it may give once: in `keymap.ron`, a key or
button listed twice for one action, bound to two actions of one group,
or a layout listed twice; in a language pack, a text key used twice.

**How to fix it.** Keep one of the two: remove the other, or rename it
if it was meant to be something else. The message names the one given
twice.

For example:

```text
fr/ui.ron: error[SH2009]: "menu.start": the key is used twice
```
