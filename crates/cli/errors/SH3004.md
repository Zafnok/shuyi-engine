# SH3004: A file the operation reads or writes can't be

Class: operation, exit code 1.

A file the operation reads (`import`'s file, `replay`'s record) or
writes (a pack, `new`'s files) couldn't be: it isn't there, a folder is
in the way, or the system refused.

**How to fix it.** Check the path and the folder's permissions; the
message ends with the system's own reason.

For example:

```text
replay: error[SH3004]: missing.ron: No such file or directory (os error 2)
```
