# SH0003: No module of that name is built in the game's engine

Class: usage, exit code 2.

`add` turns on a module the game's engine builds: a crate of the engine
with its catalog metadata. The name given is none of them. It may be
misspelt, or it may be a module the catalog lists as planned or parked,
which isn't built yet.

**How to fix it.** Pass one of the names the message lists, with or
without `shuyi-` (`physics` or `shuyi-physics`). `shuyi modules` lists
the catalog by concern, each answer with its status and the modules
built.

For example:

```text
add: error[SH0003]: shuyi-physics is in the catalog but not built yet: rigid-body physics is parked (1128)
```
