# SH2004: Several files could be the asset

Class: content, exit code 1.

An asset named without an extension matches more than one file:
`images/card` with both `images/card.png` and `images/card.txtimg`
there. The engine won't guess which is meant.

**How to fix it.** Name the file meant with its extension, or remove the
others.

For example:

```text
base/images/card: error[SH2004]: 2 files could be this image: base/images/card.png, base/images/card.txtimg; name the one meant with its extension
```
