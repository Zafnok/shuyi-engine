# SH2006: A file is bigger than its format reads

Class: content, exit code 1.

The file is bigger than its format's limit, or the registry's: 4 MiB for
the engine's text formats, 16 MiB for the others unless a format says
otherwise. It was refused before being read.

**How to fix it.** Make the file smaller, or split it into several. A
game that means to read bigger files raises `Formats::limits`.

For example:

```text
base/data/big.ron: error[SH2006]: the file is 5000000 bytes; the "ron" names format reads at most 4194304
```
