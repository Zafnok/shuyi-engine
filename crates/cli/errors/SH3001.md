# SH3001: The game's tools don't offer the operation

Class: operation, exit code 1.

The operation runs the game, and the game's tool program leaves the
`GameTools` method it needs at its default. The message names the
method.

**How to fix it.** Write that method in the game's tool program (the
grid template's `crates/game/src/tools.rs` writes each one), or don't
run that operation on this game.

For example:

```text
bots: error[SH3001]: the game's tools don't offer bots (GameTools::bots)
```
