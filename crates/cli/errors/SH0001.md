# SH0001: The command's arguments or input are wrong

Class: usage, exit code 2.

A command was given arguments it doesn't take, too few, or values it
refuses: an unknown command or option, a number out of range, a template
that doesn't exist, a folder for `new` that isn't empty, a code
`explain` doesn't know. With `--json`, an operation's input refused for
the same reasons.

**How to fix it.** Read the usage printed with the error (its `help`),
change the command, and run it again. Nothing was done, so nothing needs
undoing.

For example:

```text
bots: error[SH0001]: games: 1 to 10000, not 0
```
