# SH3009: The built program holds a path of the build machine

Class: operation, exit code 1.

A `--release` build (`export --release`, or `web --release`) remaps the
paths it was built from to short fixed names: the workspace to the
game's package name, Cargo's home to `/cargo`, rustup's to `/rustup`,
and the target folder to `/target`. Then it searches the built program,
or the `.wasm`, for the home folder, Cargo's home and the game's
folders, with either slash. One was still there, so the package would
carry the builder's user name and folders: it was refused. The message
names the file and the path found.

**How to fix it.** The path is usually code built from a folder that
isn't remapped: the engine, or another crate, depended on by a path
outside the game's workspace. Depend on it by a git revision, or keep
its checkout inside the game's folder. Keep Cargo's home and the target
folder where Cargo puts them, or set `CARGO_HOME` and
`CARGO_TARGET_DIR` for the export too. Then export again.

For example:

```text
export: error[SH3009]: the build holds a path of the build machine: dist/export/linux/game-0.1.0-linux/game holds /home/me; the package is refused
```
