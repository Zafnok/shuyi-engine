# SH2001: A text file's syntax is wrong

Class: content, exit code 1.

A text file of the game's content (a RON file, a map, a dialogue)
doesn't parse: a missing comma or bracket, a misspelt field, a value of
the wrong type. The problem gives the file, the line and the column
where reading stopped.

**How to fix it.** Open the file at that line and column and fix what
the message says was expected there. The mistake is often just before
it: an unclosed bracket, or a missing comma on the line above.

For example:

```text
files/stage.ron:3:4: error[SH2001]: Expected comma
```
