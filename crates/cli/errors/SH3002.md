# SH3002: The game's tools failed

Class: operation, exit code 1.

The game's tool program ran the operation and returned an error of its
own: its files didn't load, its record didn't parse, its bots couldn't
start.

**How to fix it.** Fix what the message says, in the game's content or
in its tools. The message is the game's own.

For example:

```text
replay: error[SH3002]: records/a.ron: no turn 4 in this record
```
