# SH3018: The file isn't a crash report

Class: operation, exit code 1.

`shuyi crash` and `shuyi replay --crash` read a crash report: the
`crash-<when>.ron` file a game writes in its data folder when it panics
(`docs/crash-reports.md`). The file given was read, but isn't one: it
isn't RON, it lacks the report's `version` or `message`, or it is over
the 2 MiB a report may be. A report cut short when it was copied, or a
record of the game's play saved on its own, reads so.

**How to fix it.** Give the report the game wrote, whole. A record of
play on its own replays with `shuyi replay <record>`, without `--crash`.

For example:

```text
crash: error[SH3018]: notes.txt: 1:1: Expected opening `(`
```
