# SH2101: The game's code or text names a key

Class: content, exit code 1.

`shuyi lint` ran `check-keys` (`shuyi.ron`'s `check_keys`) and found a
key named directly: a key or button type (`Key::`, `Button::`) or a
keyboard read outside the key pipeline's files, or a key in text shown to
the player (`"press Space"`, `"[F]"`, `WASD`). The player can bind any
key to any action, so the game reacts to actions, and text names a key
through the player's keymap.

**How to fix it.** React to an action instead of a key, and name a key in
text through the player's keymap. The message says what was found and
what the project says to do.

For example:

```text
crates/game/src/stage.rs:12: error[SH2101]: names a key or button with `Key::` — react to an action (the keymap names the keys), or name a key through the player's keymap
```
