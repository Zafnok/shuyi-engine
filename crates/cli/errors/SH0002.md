# SH0002: No game is running in the MCP session

Class: usage, exit code 2.

A session tool of the MCP server (`shuyi mcp`) was called, and no game
is running in its session: `step`, `scene`, `frame_png`, `events`,
`reset` or `stop` before `start`, after `stop`, or after the game's tool
program stopped (`SH3005`).

**How to fix it.** Call `start` first, with the game's folder as
`project` if the server doesn't run in it, then the other tools.

For example:

```text
step: error[SH0002]: no game is running: call `start` first
```
