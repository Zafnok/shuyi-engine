# SH2007: The pack differs from its sources

Class: content, exit code 1.

`check --baked` baked the game's pack and read every asset from it and
from its source: they differ, the pack lacks a file or has one the
sources don't, or a file kept as its own bytes changed.

**How to fix it.** Bake the pack again (`shuyi bake`): a pack made
before the sources changed differs from them. If a fresh pack still
differs, the kind's packed format loses something: report it with the
kind's name.

For example:

```text
pack/data/palette.ron: error[SH2007]: the palette read from the pack differs from the one read from its source
```
