# SH1008: gh isn't signed in to GitHub

Class: setup, exit code 3.

`shuyi repos` acts on your GitHub account through `gh`, which isn't
signed in to github.com (`gh auth status` says so). Nothing was made.

**How to fix it.** Run `gh auth login`, choose GitHub.com, and sign in.
Its default scopes are the ones `repos` needs. Then run `shuyi repos`
again.

For example:

```text
repos: error[SH1008]: gh isn't signed in to github.com
```
