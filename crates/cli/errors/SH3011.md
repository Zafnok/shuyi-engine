# SH3011: The export's build, or writing its package, failed

Class: operation, exit code 1.

`export` ran the build, or a tool that makes the package (`objcopy`,
`lipo`, `codesign`), and it failed, or a file of the package couldn't
be written. The message names the command and its exit status, or the
file and the system's reason. The build's own output, a compile error
say, is printed above it.

**How to fix it.** Fix what the message and the output above it say: a
compile error in the game, a tool that failed, a folder that can't be
written. Then export again.

For example:

```text
export: error[SH3011]: cargo build -p game --bin game --target x86_64-pc-windows-gnu --release exited with exit code: 101
```
